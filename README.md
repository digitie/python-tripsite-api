# python-tripsite-api

야놀자, 여기어때, 네이버예약에 개인 계정으로 로그인해 **본인의 예약 내역**을 Playwright로
조회하는 Python 라이브러리이자, 이를 AI 에이전트가 사용할 수 있도록 감싼 MCP 서버입니다.

> 설계 배경과 상세 아키텍처는 [`docs/DESIGN.md`](docs/DESIGN.md)를 참고하세요.
> 설치/사용법/보안 안내는 구현이 진행되는 대로 이 문서에 채워질 예정입니다
> (진행 상황은 리포지토리의 PR 목록 참고).

## 상태

현재 공통 프레임워크(데이터 모델/설정/브라우저 세션 관리/어댑터 인터페이스)를 구현 중입니다.
야놀자/여기어때/네이버예약 개별 어댑터와 MCP 서버는 뒤이어 추가됩니다.
